# Blender models

One script per model: blender/<modelId>.py (uses studio2/blender/bl_kit.py), built with: node studio2/blender-build.mjs --episode episodes/<id> --model <modelId>. The GLB lands in scene2/models/glb/. Rule (owner 2026-11-09): every model is sculpted in Blender and exported, never built from code primitives.
