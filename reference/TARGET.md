# Quality target in one page

Copy the reference's story skeleton, change only the topic: immediate action opening -> reveal the scale -> cost / empty wallet gag -> rival -> first test fails -> damage found -> fix -> explainer cutaways -> second test works -> opening day with a crowd -> POV / danger beat -> payoff on the rival -> final reaction and an immediate cut. 16 beats; see `episodes/time-machine-success/SPEC-BEATS.md` for a worked example.

What the reference has that a film must also have:
- Acting inside every shot (eyes, brows, mouth, head, hands on separate timings), never a held pose.
- Setup -> contact -> consequence for every spoken action, visible on screen.
- Camera that travels and reveals (push, pull-back, orbit, POV), foreground/background layers, varied situations (not one street), a night or lamp-lit shot, motion blur on fast action.
- Readable explainers: one clear visual metaphor per fact, big in-world labels, nothing overlapping, one floor only.
- Narration, score and sound effects mixed to about -14 LUFS with the voice on top.

Characters (fixed by the user): real 3D head and torso, 2D face ink, 2D stick limbs with arm 0.285/0.255 m and leg 0.37/0.37 m, never stretched; if a hand cannot reach, move the actor or the prop.

Acceptance is the user's call. The agent reports what it measured and what it could not judge (nobody listened to the full mix or watched the film continuously unless the user says so).
